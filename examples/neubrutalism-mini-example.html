What makes this different?

Unlike Bootstrap or Tailwind, you don't need to memorize classes. Just write <button> and it's styled. Write <table> and it's responsive.

Can I customize it?

Absolutely! Override CSS variables to change colors, fonts, spacing, and more. The library is designed to be easily customizable.

Does it work with React/Vue/Angular?

Yes! Since it's just CSS with element selectors, it works with any framework or no framework at all.
