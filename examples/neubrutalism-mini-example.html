What is Neubrutalism CSS?

Neubrutalism CSS is a minimal, lightweight CSS framework designed for building beautiful, responsive websites without the bloat.

How do I use it?

Simply include the CSS file in your HTML and start using the classes. Check the documentation for examples.

Is it compatible with other frameworks?

Yes! Neubrutalism CSS is designed to be lightweight and non-intrusive, making it compatible with most other frameworks.
