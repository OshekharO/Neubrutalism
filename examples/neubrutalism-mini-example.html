What is Neubrutalism CSS?

Neubrutalism CSS is a classless-first CSS framework. You write standard HTML elements and they're automatically styled. No classes needed for basic styling.

How do I use it?

Simply include the CSS file in your HTML and start writing standard HTML. Everything from headings to tables to forms is automatically styled.

Is it responsive?

Yes! Tables scroll horizontally on mobile, images scale automatically, and all form elements are touch-friendly.

How do I enable dark mode?

Add the nb-dark class to your <html> element, or use data-theme="dark".
