Neubrutalism CSS

A classless-first CSS framework. Just write HTML — it automatically looks great. No classes to memorize, no complex layouts to learn.

Why Neubrutalism CSS?

100% Classless

Write standard HTML elements — headings, paragraphs, tables, forms — and they're automatically styled. No class="btn btn-primary" needed.

Responsive by Default

Tables scroll horizontally on mobile. Images scale automatically. Everything just works.

Dark Mode

Add a single class nb-dark or use data-theme="dark" to enable dark mode.

Tiny Size

Only ~11KB minified. No bloat, no dependencies, no JavaScript required.

What is Neubrutalism CSS?

A classless-first CSS framework where you just write HTML and it looks great. No classes needed for basic styling.

How do I use it?

Simply include the CSS file in your HTML and start writing standard HTML elements. Everything is automatically styled.

Is it responsive?

Yes! Tables scroll on mobile, images scale automatically, and all form elements are touch-friendly.
