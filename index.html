How does it work?

The library styles all HTML elements directly using semantic selectors. Just write standard HTML and it automatically looks great.

Is it really classless?

Yes! All basic styling uses element selectors. You never need classes for buttons, forms, tables, or any common element.

How do I enable dark mode?

Add the nb-dark class to your <html> element, or use data-theme="dark".
